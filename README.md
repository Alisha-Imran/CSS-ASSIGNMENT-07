CardioCare - Heart Care Website

Description

CardioCare is a responsive healthcare website designed for a heart care clinic. It provides information about medical services, doctors, departments, and patient care.

Features

- Responsive website design
- Navigation bar
- Hero section
- Appointment section
- About section
- Medical services
- Why Choose Us section
- Statistics section
- Departments
- Patient testimonials
- Blog section
- FAQ section
- Contact section
- Footer

Technologies Used

- HTML5
- CSS3
- Bootstrap Icons / Font Awesome
